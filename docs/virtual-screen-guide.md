# 虚拟屏开启与使用

无障碍负责读取控件和中文输入。**开启无障碍后，虚拟屏仍需要单独创建。** `VSCREEN_NOT_RUNNING` 表示目前没有运行中的虚拟屏，不代表要重新安装环境。

1. 使用 **Standard 标准版**，手机为 **Android 11 或更高**。Low 兼容版暂不支持虚拟屏。
2. 打开 DSHA **设置 → 设备能力授权**，连接 **ADB、Shizuku 或 Root 中的一种**。没有 Root 时，在系统开发者选项打开“无线调试”，然后按 DSHA 的 ADB 配对页完成配对和连接，确认通道已连接。仅打开系统无线调试开关不等于已经连接 DSHA。
3. 在“设备能力授权”点 **打开虚拟屏**，再点 **创建竖屏** 或 **创建横屏**。等画面出现、页面显示“虚拟屏已开启”。页面顶部随时可以打开“使用说明”。
4. 点 **应用 → 选择**，选中想操作的应用，再点 **启动**。应用会显示在虚拟屏中，可以在预览里点击和滑动。
5. 需要读取控件树或输入中文时，开启 **DSHA 无障碍**。让助手操作，还要按 DSHA 的提示确认本次读屏与操作授权，并选择虚拟屏作为操作目标。

### 虚拟屏预览怎么看

虚拟屏运行时，DSHA 里默认在屏幕顶部显示一条**蓝色呼吸线**，并写出正在操作的应用；点它打开虚拟识屏页，点右侧 **×** 收起。提示条只显示，不会把你的触摸转发给虚拟屏，也不会盖住状态栏。

收起后不会因为新建虚拟屏或重启 App 自己回来。想换形态或重新打开：**设置 → 设备能力授权 → 虚拟屏预览**，有三档：

- **提示条（默认）**：顶部呼吸条，显示正在操作的应用，不占屏幕。
- **完整预览**：旧的页内小窗，可以拖动，点画面打开控制页。
- **关闭**：不显示任何预览。

系统悬浮预览是另一个开关，需要悬浮窗权限；它显示时页内提示条和小窗会自动让位。虚拟屏停止、或当前就在虚拟识屏页里时，提示条不显示。


出现 `VSCREEN_NOT_RUNNING` 时，先确认设备通道仍然连接，再点击创建按钮。此前点过“关闭”、通道断开或授权撤销后，需要重新连接和创建；无需清数据或重新解压。

如果创建按钮报其它错误，到 **设置 → 自检与诊断** 查看记录、导出日志。开启无障碍不能替代设备通道，也不能消除厂商系统的兼容问题。

不用时在虚拟屏页点 **关闭**，回收临时虚拟屏。退出预览页与关闭虚拟屏是两个不同操作；需要结束时请使用“关闭”。
