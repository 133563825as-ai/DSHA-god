# Current delivery and historical evidence

Updated: 2026-11-08. This English entry describes the maintained build346 source and links historical records separately. It is not a remote-publication receipt.

> **build346 `0.2.1-rc.5-20261109.0700-dsh0.2.2-rc.1`.** This build carries two lines. Keep-screen-on and power saving become hard-exclusive: both default off; turning either on forces the other off, turning one off never touches the other, and repeated enabling neither re-saves nor re-notifies; the Settings page persists the decision and syncs the service and window flag, with a bilingual toast when it force-disables the other side; on startup a historical double-on state is normalized to keep screen on and disable power saving, silently, and written back; `util/PowerModePolicy` is pure logic with unit tests. Physical-screen activity history M1 records, in memory only during a phone task, target changes / user taps / scrolls / content changes / assistant actions (about 120 s / 64 events); task end, pause and accessibility disconnect or reconnect clear it immediately; nothing is written to disk, backups or diagnostics; sensitive apps keep only target changes, password fields only "already entered", and IME / own-overlay events are dropped. Every `/app/ui/*` JSON result now carries `recentActivity` (at most 3 events since the previous result); a new `GET /app/ui/history?since=&limit=` serves incremental reads (default 20, max 100; M1 returns no images), and the bundled `dsh-computer-use-android` adds the `android_history` tool. The accessibility config adds click / scroll event types, the action executor records `ASSISTANT_ACTION` explicitly and uses a 1.5 s dispatch window to separate user from assistant, and execution-time guard semantics are unchanged. This build includes one managed-runtime update: `runtime-descriptor` is recomputed to `7b1ca97d` (DshaAccessibilityService / HttpShellService / ScreenActionExecutor / new ScreenActivityRecorder / accessibility config / plugin server.cjs); fixed inputs stay frozen at the locked 20261105e, and the bundled `dsh-web-mobile` stays upstream 3.3.1 and default-enabled. VersionCode 346, package `io.github.sunsetrne.dsha`, single Standard, Mod-owned release certificate, bundled DSH 0.2.2-rc.1. build344 / build345 / build346 formal-package overwrite acceptance and the 345→346 first overwrite are **not yet validated on device**; device acceptance of the released build338–345 follows their own records.
