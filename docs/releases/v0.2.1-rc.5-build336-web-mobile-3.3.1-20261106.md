关键判据：

1. 上游 README 的 3.4.0 更新内容与现代码一致：`4e71eb67` 把 3.4.0 内容**重编号为 3.3.1**（上游
   先发 3.4.0，随后 3.3.0 → 3.3.1 → 3.3.2 改号；最终 3.3.2 的「`react` 标为可选 peer」修复并入
   3.3.1 版本号，提交 `be9b7fc` + 合并 `4e71eb6`）。**因此固定 HEAD（3.3.1）而不是 v3.3.0 / v3.4.0
   标签**：v3.3.0 / v3.4.0 的 `react` 仍是必选 peer，宿主没有 react 时依赖门槛会判 missing。
2. 宿主的 `plugin-dependencies.py` 只把 `@deepseek-ai/dsh-*` 的缺失 peer 当宿主服务放行；其它
   必选 peer 缺失会进入 `missing` / `dependencies-incomplete`，所以 `react` 必须可选。
3. 上游 3.3.1 删除 `lib/file-transfer.js`（`b52b2cb`），而 DSHA 的 `tools/mobile-server/index.js`
   仍 `import './file-transfer.js'`；因此该模块从「上游成员」改为「仅本地追加成员」，字节继续由
   `tools/file-transfer/file-transfer.js` 生成并核验，source map 规则不变。
4. 上游 3.3.1 已接管若干 DSHA 旧补丁：宽屏触屏档收起归档/置顶（712999a / PR #257）、快捷键
   弹层的首次自动聚焦守卫、可见视口变量发布（`--dsha-mobile-visible-vh` / `-viewport-top`）、
   frame 顶部 safe-area 变量；本地补丁按此逐条重放或删除（见第四节）。
5. 上游把整页遮罩改成 `div`，0.2.2 之后通用 `:active` inset 染色不会再落到遮罩上；旧的
   `DSHA_BACKDROP_PRESS_V1` 失去对象，删除。

  收口；0.2.2 手机设置弹层已回到宿主官方全屏，旧的通用弹层选择器（0.2.1 DOM）删除。
- `DSHA_FONT_FAMILY_ROW_V1`：宿主 0.2.2-rc.1 仍是 `maxLength=200` / `field` / `_wrap` 结构；固定
  上游 3.3.1 仍无该选择器。

  3.3.1 仍是旧的「连接条 `:has()` 存在性」判据，本补丁继续保留（3.3.1 的锚点改为 CSS 规则本体）。

- 多语言字典与 live-locale 订阅：zh-Hant / ru / ja / ko / ar / pt / la / fr；按 3.3.1 的键集删除

## 七、真机待验（build336 发布前，需用户 / 主会话）

1. 覆盖安装（build335 → build336，升级前插件默认禁用）：进入主界面不白屏、侧栏只有一个设置入口、
   footer 设置入口不重复，`dsh-web-mobile` **默认启用**（插件页开关为开）；
2. 插件页关闭 → 重启 Web 恢复默认界面；再打开 → 重启后竖屏壳生效，跨 Web 重启保持；
3. 竖屏核对：顶栏开关不被裁、文件键可见、页签不叠字、文件面板标签条不被顶栏盖住、设置弹层为
   官方全屏且字体族行不被压成 1 字/行、抽屉开关与 footer 齿轮不重叠；
4. 若任一项失败：回退 `builtin-plugins.json` 的一行改动（恢复 `defaultDisabled: true`）并重跑
   注册表 / 描述符生成器；插件字节与上游同步可以保留。
