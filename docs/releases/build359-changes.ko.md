- 중지/재시작 신뢰성(T154, `5b517e7ff` + 게이트 수정 `5e4509d2b`): 일반 중지에서 SIGTERM 유예 창(6.5s) 후에도 프로세스가 살아 있고 명령줄이 여전히 이 설치의 관리 proroot bridge이면 "동일 출생 신원 + 이 설치의 proroot bridge/런처"를 두 번 검증한 뒤 SIGQUIT으로 제어 승격하고, 1.5s 뒤에도 살아 있으면 다시 두 번 검증해 SIGKILL로 승격하여 2s 안에 종료를 확인합니다. 신원/PID 기록/신호 중 하나라도 불일치하면 현장을 보존하고 영수증에 신호 수준을 기록합니다. 강제 중지 증거 폴백: 중지 스캔은 두 번의 커널 검증이 일치한 잔류 사실을 보존하여 PID/신원 파일이 없거나 오래되었거나 이미 은퇴해도 후보를 준비할 수 있고, 신호 전에 다시 두 번 검증하여 불일치면 거부합니다. 시작 전 중지가 실패하면 시작 페이지가 바로 "강제 종료" 진입점을 제공합니다(09:13 현장처럼 앱을 다시 시작할 필요 없음). 강제 중지 허용은 미확인 중지 결론의 명시적 허용 목록으로 바뀌었고, 정상 시작 후에는 진입점이 닫혀 있어야 합니다. 레드라인 불변: 신원이 검증된 PID에만 신호를 보내고 이름/포트/맨 PID로 종료하지 않으며 UNKNOWN을 재생하지 않습니다.
